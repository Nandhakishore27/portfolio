# Nandhakishore O — Personal Portfolio

A responsive personal portfolio built with plain HTML, CSS, and JavaScript.

## Run locally
1. Extract `nandhakishore_portfolio.zip`.
2. Open the `nandhakishore_portfolio` folder.
3. Double-click `index.html` to open it in your browser.
4. For a more developer-friendly workflow, open the folder in VS Code and use the Live Server extension.

## Personalize before publishing
- Add your actual photo at `assets/profile.jpg` (JPG recommended). Until then, the site displays an NK placeholder.
- In `index.html`, replace `YOUR_EMAIL@example.com` with your real email.
- In `script.js`, update the `links` object with your real LinkedIn, GitHub, resume, and project URLs.
- Add your resume PDF at `assets/Nandhakishore-Resume.pdf` if you use that path in `script.js`.
- Verify the 12th-standard score before publishing; it is marked for verification in the page.
- Confirm the experience start date and certification details.
- Only list certifications you have actually earned.

## Contact form note
The contact form opens the visitor's email application using `mailto:`. It does not save submissions to a database or send messages from a server. A working backend or form service is needed for server-side submissions.

## Publish online
You can publish this static site with GitHub Pages, Netlify, or Cloudflare Pages. Upload the files while keeping the folder structure intact.
